  🏋️ Gym Slot Booking System
  
  A full-stack Gym Slot Booking System built with the MERN stack. The application allows gym members to browse available classes, book slots, manage their bookings, and receive email notifications. Trainers can manage gym classes, while admins can manage users and monitor all bookings.
  
  The project focuses on authentication, role-based authorization, slot management, booking validation, email notifications, and a responsive user interface.
